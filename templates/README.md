# ビジタースライドのテンプレート

**実際に運用されているpptxから、スライドを1枚ずつ取り出して作ったものです。**
デザイン・画像・動画・フォント・配色は運用中のものそのままで、中身は触っていません。

`⚙️ 設定` ＞ `PowerPointテンプレート（ビジター用）` から登録して使います。

| ファイル | 種類 | 元 | 見出し |
|---|---|---|---|
| `BNI_テンプレート_ビジター紹介.pptx` | ビジター紹介（3人1枚） | スライド1 | 歓迎 本日のビジター |
| `BNI_テンプレート_ゲスト紹介.pptx` | ゲスト紹介（3人1枚） | スライド1 | 歓迎 本日のゲスト |
| `BNI_テンプレート_代理紹介.pptx` | 代理紹介（3人1枚） | スライド1 | 代理出席の方々 |
| `BNI_テンプレート_ビジタープレゼン.pptx` | ビジタープレゼン（1人1枚） | スライド3 | Visitor's Presentation |

紹介・ゲスト・代理は**いずれもスライド1**から作っています。
元ファイルのスライド2（代理）は、その週が2名だったため3枠目の見出し
（氏名／専門分野／招待者）が削除されていました。3名いる週に使うと3枠目だけ
見出しの無い表示になるため、枠の揃っているスライド1を使い、見出しの文字だけ変えています。

## 差し込みの仕組み

文字は `{{トークン}}` ではなく **シェイプID** で差し替えます。
`assets.js` の `TEMPLATE_KINDS_` が、登録時にこのIDの有無を検査します。

**ビジタープレゼン（1人1枚）**

| ID | 入る内容 |
|---|---|
| 25 | 氏名 + ` 様` |
| 27 | 会社名 |
| 29 | `【` カテゴリー `】` |

**紹介・ゲスト紹介・代理紹介（3人1枚）**

| 枠 | 専門分野 | 招待者 | 氏名 |
|---|---|---|---|
| 1人目 | 19 | 20 | 21 |
| 2人目 | 25 | 26 | **28** |
| 3人目 | 31 | 32 | 33 |

2人目の氏名が27ではなく**28**なのは、元ファイルがそうなっているためです。

**見出しはシェイプID 15** です。「まとめて作成」はこのIDの文字を節ごとに
差し替えることで、1つのテンプレートからビジター・ゲスト・代理の3種類を作ります。

人数が3の倍数でないときは、余った枠に空文字が入ります。
そのため**枠の中に固定の文字を置かないでください**（空き枠にその文字だけ残ります）。

## 作り直す

運用中のpptx（3枚構成）を `real.pptx` として置いて実行します。

    python3 tools/extract_visitor_templates.py

デザインを変えるときは、**シェイプIDを変えないまま**PowerPointで直接編集してください。
IDが変わると登録時に「レイアウトが一致しません」と出ます。

# メンバープレゼンのテンプレート

リポジトリには入れていない（作り直した後でも2MBあるため）。
Driveに置いて、`⚙️ 設定` ＞ `大きなスライド` の **メンバープレゼン** にリンクで登録する。

## 作り直した経緯

もとは「メンバープレゼンスライド 自動生成ツール」という単体のHTMLで、その中に
テンプレートpptxがbase64で埋め込まれていた（61枚・14.7MB）。
ただし生成に使うのは**2枚だけ**で、残りの59枚と写真は出来上がりに一切出ないのに、
毎回サーバーが読み書きすることになっていた。

    python3 tools/build_member_presen_template.py <元のpptx> <出力先pptx>

で、次のように作り直したものを使う。デザイン・座標・フォント・配色は触っていない。

| | 元 | 作り直したもの |
|---|---|---|
| パーツ数 | 306 | 25 |
| 大きさ | 14.7MB | 2.0MB |
| スライド | 61枚 | 2枚 |
| 氏名・会社名 | 実在の方のもの | `氏名` `会社名` `【カテゴリー】` |
| 写真 | 実在の方のもの | 差し込み用の見本（灰色） |
| カウントダウン | クリックで開始 / 0.4秒で次へ | 自動で開始 / 31秒で次へ |

## 2枚のひな形

| スライド | 役割 |
|---|---|
| 1枚目 | 業種区分の扉ページ（区分名・先頭の方の写真・専門分野とメンバーの表） |
| 2枚目 | 個人ページ（写真・氏名・会社名・【カテゴリー】・NEXT➡・30秒カウントダウン） |

生成時はこの2枚をひな形に必要な枚数を作り、元のスライドと、どこからも使われなく
なった画像を取り除く。**何枚目かは見ていない**ので、順番が入れ替わっても動く
（下のシェイプIDで見分けている）。

## 差し込み口（シェイプID）

`member_presen_srv.js` の `MP_OVERVIEW_` / `MP_INDIVIDUAL_` がこのIDを見ている。
1つでも欠けていると、その場で分かるようにエラーで止まる。

**扉ページ**

| ID | 入る内容 |
|---|---|
| 11 | 業種区分名 |
| 31 | Next Presenter の氏名 |
| 2 | 先頭の方の写真（関係ID `rId3`） |
| 6 | 専門分野／メンバーの表（見出し1行＋7行） |

**個人ページ**

| ID | 入る内容 |
|---|---|
| 56 | 氏名 |
| 2 | 会社名（1〜3行。行数に応じて枠の高さも差し替える） |
| 12 | `【` カテゴリー `】`（会社名の枠の真下に置き直す） |
| 14 | NEXT➡ の氏名（最後の方では図形ごと消す） |
| 6 | NEXT➡ の文字（同上） |
| 3 | 写真（関係ID `rId2`） |
| 43〜74 | 30秒カウントダウンの数字（触らない。アニメーションの対象） |

デザインを変えるときは、**シェイプIDを変えないまま**PowerPointで直接編集すること。

## カウントダウンと自動送り

数字を書いた**白い箱を重ねておき、1秒ごとに上から1枚ずつ消して**下の数字を見せる
仕掛け。消す手順は `<p:timing>` に入っている。
数字は Arial Black 96pt、残り10秒からは赤（`CF2030`）、それより上は灰（`64666A`）。

**自動で次のスライドへ進ませるには、3つ揃っている必要がある。**

| | 場所 | 元のテンプレート | 直したあと |
|---|---|---|---|
| (1) カウントダウンがスライド表示と同時に始まる | スライドの `<p:cond delay="…"/>` | `indefinite`（クリック待ち） | `0` |
| (2) 何秒で次へ進むか | スライドの `<p:transition advTm="…">` | `400`（0.4秒） | `31000` |
| (3) 保存済みのタイミングを使う | **`ppt/presProps.xml` の `<p:showPr useTimings="…">`** | `0` | `1` |

**(3)が0のままだと、(1)(2)を直しても絶対に自動で進まない。**
PowerPointの「スライドショーの設定 ＞ 保存済みのタイミングを使用」に当たる設定で、
プレゼンテーション全体に効く。自動送りが効かないときは、まずここを疑うこと。

生成時に `mpAutoAdvance_()` と `mpUseTimings_()` が3つとも設定するので、
**古いテンプレートのままでも効く**（画面のチェックを外すと書き換えない）。

## 秒数を変える（2分30秒プレゼン）

テンプレートに入っているのは30秒ぶんだけ。別の秒数にするときは
`mpSetCountdown_()` が数字の箱とアニメーションごと作り直す。

- 60秒以上は **`2:30` のような分:秒**の表示になる
- 文字数が増えたぶん、箱に収まる大きさまで文字を小さくする（2:30なら86pt）
- 色の付け方（残り10秒から赤）と消す間隔（1秒）は30秒のときと同じ
- 書式は見本の箱からそのまま引き継ぐので、フォントや位置は変わらない

## 検査

    python3 tools/check_member_presen.py <テンプレート.pptx>

実物に対して本番と同じコードを動かし、zipの整合性・切れた参照・文字・座標・
写真の切り抜き・カウントダウンの設定まで機械的に確かめる。
業種区分の巡回だけは、テンプレートが無くても単体で確かめられる。

    node tools/mp_check_rotation.js

配置を目で見たいときは、出来上がったpptxから確認用のHTMLを作れる。

    python3 tools/mp_preview.py <出来上がり.pptx> 1 2 3 > preview.html

# 定例会スライド（前半・後半）のテンプレート

リポジトリには入れていない（前半 約27MB・後半 約23MB）。
Driveに置いて、`⚙️ 設定` ＞ `大きなスライド` の **定例会スライド（前半）／（後半）** にリンクで登録する。

実際に使った週の出力（pptx）から、毎週手で書き換えていた箇所だけを差し込み口 `{{ }}` に
置き換えて作った。デザイン・座標・画像・枚数は元のまま。

    python3 tools/build_meeting_first_template.py  <前半の出力.pptx> <テンプレート.pptx>
    python3 tools/build_meeting_second_template.py <後半の出力.pptx> <テンプレート.pptx>

## 差し込み口

**前半（79枚）**

| ページ | 差し込み口 |
|---|---|
| メンバーシップ委員会による報告 | `{{求める専門分野1}}`〜`{{求める専門分野12}}`（表のマス）・`{{開放カテゴリー}}`・`{{審査中カテゴリー}}` |
| Main Presenter of the Week | `{{メインプレゼン1氏名}}` `{{メインプレゼン1会社名}}` `{{メインプレゼン1カテゴリー}}`（2人目も同じ） |

**後半（21枚）**

| ページ | 差し込み口 |
|---|---|
| Words of Recommendation | `{{推薦のことば1氏名}}` `{{推薦のことば1会社名}}` `{{推薦のことば1カテゴリー}}`（2人目も同じ） |
| 賞品の抽選のコーナー | `{{抽選1氏名}}` `{{抽選1会社名}}` `{{抽選1カテゴリー}}`（2人目も同じ） |

左右に写真とお名前が並ぶページ（メインプレゼン・推薦のことば・抽選）は、`{{○○1氏名}}` が
載っているページを探し、**それぞれの方の氏名の差し込み口の真上にある枠**の写真を差し替える。
大きさだけで選ぶと、抽選コーナー（後半21枚目）の中央下にある飾りの画像（プレゼントの絵。
写真の枠と同じくらいの大きさ）を枠と取り違え、右の枠に元の写真が残ってしまうため。
名前が空の方・写真が見つからない方の枠は、元の写真が残らないよう枠ごと消す。

写真は1回の作成の中で1人1枚だけ取り込み、リファーラル発表・推薦のことば・抽選で使い回す。
画像の名前（`ppt/media/mpphoto○.jpeg`）は既存のものと重ならないように付ける
（以前は処理ごとに1番から振り直していたため、後の処理が前の写真を上書きし、
リファーラル発表の最初の方のページに抽選の方の写真が入っていた）。

## 差し込み口を置かずに、中身で見つけるページ

番号を決め打ちにしないので、ページを並べ替えても動く。

| ページ | 見つけ方 | すること |
|---|---|---|
| 表紙など | `第526回` `2026年07月22日` の形の文字 | 開催回・開催日に書き換える |
| コアバリュー（7枚） | 英語のコアバリュー名（Givers Gain など） | その週の1枚だけ表示 |
| 一般規定（12枚） | ノートの通し番号 `J-04164`〜`J-04175`（1番〜12番） | その週の1枚だけ表示 |
| ウィークリープレゼンテーションの見出し | 「ウィークリー」「プレゼンテーション」を含み、「終わりましたか」を含まない最初のページ | 直後にメンバープレゼンのページを差し込む |
| アンバサダー・ディレクター | 見出しから「全員終わりましたか？」までの、氏名入りの `WEEKLY PRESENTATION` のページ（`苗字　名前` のままの下書きは除く） | チェックした方だけ表示 |
| リファーラル発表 | `REFERRAL PRESENTATION` のページ（後半） | 名簿のNo.順に人数ぶんへ増やす |
| 音楽・動画 | 図形の名前（曲名） | 差し替え・音量の変更 |

## 前半にメンバープレゼンのページを差し込む

メンバープレゼンのテンプレートでページを作り、前半スライドへ移し替える（`splice_srv.js`）。
**2つのテンプレートが同じ土台（レイアウト `2_Blank`・テーマ `BNI Colors`）であることが前提。**
ページのレイアウトは名前で付け替えるので、どちらかのレイアウト名を変えると見た目が崩れる
（その場合は作成時にお知らせする）。ノートは持ってこない。

自動送りのページを入れるときは `ppt/presProps.xml` の `useTimings` を `1` にし、
自分で作っていないページに残っている `advTm`（0.4秒など）を外す。
元は効いていなかった値なので、外してもほかのページはこれまでどおりクリックで進む。

## 検査

    node tools/check_meeting_output.js <展開したテンプレート> <routine.json> <members.json> <開催日>
    python3 tools/mtg_zip_check.py <出力ディレクトリ> <確認用.pptx>

`MTG_MP_DIR=<展開したメンバープレゼンのテンプレート>` を付けると、前半にメンバーのページを
差し込むところまで通す。`MTG_REGION='坂爪アンバサダー'` でリージョン参加者の記載を差し替えられる。
