# 初期導入の手順（新しいチャプターで始めるとき）

このシステムを、**新しいチャプターが空の Google スプレッドシートから使い始める**ための手順です。
導入を担当する方（パソコンでコマンドを打てる方）向けに書いています。

毎週の使い方は [MANUAL.md](../MANUAL.md)（システムのメニュー「❓ 使い方（ヘルプ）」と同じもの）を見てください。
ここでは、最初の1回だけの準備を順番に説明します。

## 全体の流れ

| # | すること | 所要時間の目安 |
|---|---|---|
| 1 | 用意するもの | — |
| 2 | 空のスプレッドシートを作る | 1分 |
| 3 | スクリプトを入れる（clasp） | 15分 |
| 4 | スプレッドシートを開き直す（初回の準備） | 1分 |
| 5 | Google の許可（認証） | 3分 |
| 6 | 休会日を入れる | 3分 |
| 7 | チャプターの設定（ここでルーティンチェックシートができる） | 3分 |
| 8 | メンバー名簿・写真を入れる | 30分〜 |
| 9 | スライドの雛形を登録する | 30分〜 |
| 10 | 役職・チーム、スピーカーローテーション、トークスクリプト | 20分 |
| 11 | メール・Gemini API・ウェブアプリ | 10分 |
| 12 | 準備の状況を確かめる | 1分 |

---

## 1. 用意するもの

- **チャプターで使う Google アカウント**（共有のアカウントがおすすめです）。
  スプレッドシートの持ち主になり、案内メールはふだん、操作した方の Gmail から送られます
- **パソコン**（Windows・Mac）と [Node.js](https://nodejs.org/)（clasp を動かすのに使います）
- **このリポジトリ**（`git clone` するか、GitHub の「Code > Download ZIP」で取り出します）

## 2. 空のスプレッドシートを作る

1. Google ドライブで「新規 > Google スプレッドシート」を作ります。
   名前は「BNI 〇〇チャプター 名簿システム」など、分かりやすいものにします
2. **何も入力しないでください。** 空のまま次へ進みます。
   空のスプレッドシートで初めて開いたときに、システムが使うシートを自動で作ります（4.）
3. 役職の方に「編集者」で共有しておきます（あとからでもかまいません）

## 3. スクリプトを入れる（clasp）

1. <https://script.google.com/home/usersettings> を開き、**「Google Apps Script API」をオン**にします
   （clasp がスクリプトを送るのに必要です）
2. スプレッドシートのメニュー「拡張機能 > Apps Script」を開き、左の歯車（プロジェクトの設定）から
   **「スクリプト ID」をコピー**します
3. パソコンで次を実行します

   ```bash
   npm install -g @google/clasp
   clasp login
   git clone https://github.com/kimuchi/BNI_Chiyoda_VisitorHost.git
   cd BNI_Chiyoda_VisitorHost
   ```

4. フォルダの直下に `.clasp.json` を作り、コピーしたスクリプト ID を入れます

   ```json
   {"scriptId": "（コピーしたスクリプトID）", "rootDir": "."}
   ```

5. スクリプトを送ります

   ```bash
   clasp push
   ```

   「Manifest file has been updated. Do you want to push and overwrite?」と聞かれたら `y` を押します。
   `docs/`・`tools/`・README などは `.claspignore` で除いてあり、送られません。

## 4. スプレッドシートを開き直す（初回の準備）

1. ブラウザでスプレッドシートを**再読み込み**します。しばらくすると、メニューバーに **「名簿システム」** が出ます
2. 右下に **「初回の準備」** のお知らせが出て、次のシートができます。最初からあった「シート1」は消えます

   | シート | 中身 |
   |---|---|
   | メンバー名簿 | 見出しの行だけ（8.で取り込みます） |
   | 業種区分マスタ（非表示） | 8つの業種区分と色（Spreading のカテゴリのグループ名と同じ） |
   | 休会日（非表示） | 空（6.で入れます） |

- お知らせが出ないとき・メニューが出ないときは、もう一度開き直してください。
  それでも出ないときは MANUAL.md の「準備：メニューが出ていないところから」を見てください
- **何か入力してあるスプレッドシートでは、初回の準備は動きません**（今まで使ってきたスプレッドシートとみなします）。
  そのときは、メニュー `⚙️ 設定` > `足りないシートを作る（ルーティンチェックシートなど）` で同じシートを作れます

## 5. Google の許可（認証）

メニュー `名簿システム` > `🔧 動作確認` > **`Googleの権限を確認・許可する`** を1回実行し、画面の案内に沿って許可します。
画面の写真つきの手順は MANUAL.md の「はじめに：初回だけ必要な『Google認証』の手順」にあります。

## 6. 休会日を入れる

メニュー `⚙️ 設定` > **`休会日`** で、分かっている休会日（年末年始など）を入れます。

**チャプターの設定（7.）より先に入れてください。** 7.で作るルーティンチェックシートの2行目（定例会の回数）は、
そのときの休会日を除いて数えます。スライドの「第○回」は、この2行目の回数を使います。
あとから休会日を足したときは、チェックシートの2行目の、その日より後の回数も直してください。

## 7. チャプターの設定（ここでルーティンチェックシートができる）

メニュー `⚙️ 設定` > **`チャプター（名前・期・定例会の回数）`** を開き、保存します。

| 項目 | 入れるもの |
|---|---|
| チャプター名 | 「チャプター」を付けずに入れます（例: `サンプル` → 画面では「サンプルチャプター」） |
| リージョン | 例: `BNI東京〇〇リージョン`（ウェブアプリのいちばん下と、トークスクリプトに出ます） |
| いまの期 | 期の番号。4月〜9月・10月〜3月の半期ごとに1つ進みます |
| 定例会の回数と曜日 | **次回の定例会の日と、その回数**。入れた日の曜日に毎週開催として数えます |

保存すると、**次の定例会の期の「【NN期】ルーティンチェックシート」** ができます。

- 1行目は開催日（定例会の曜日の毎週）、2行目は回数（休会日の週は空・灰色）、3行目は担当割り振り、4行目は見出しです
- 5行目からの項目（内容・担当・期日・曜日目安・備考）は、スライド・役職ごとの入力・トークスクリプトが読む、
  一般的なものです。**期日のある項目が、役職ごとの入力で必須**になります。曜日目安は定例会の曜日から数えます
- 項目は足したり、担当や期日を変えたりしてかまいません（役職ごとの入力の画面の項目も、そのとおりに変わります）。
  ただし、次の**項目名は、スライドやトークスクリプトが名前で読む**ので、名前を変えないでください

  > 定例会回数・担当割り振り・メインプレゼン・2分30秒プレゼン・ウィークリープレゼン・推薦の言葉・一般規定・
  > BNI目的と概要・募集カテゴリー・開放カテゴリー・審査中カテゴリー・リージョン参加者・真正度確認・
  > 代理・欠席・医療欠席・体験談・エデュケーション・新入会・更新対象者（30日前・60日前・90日前）
  > のほか、トークスクリプトのひな形の `{ルーティン:…}` で使っている項目

- 期の番号を間違えて保存したときは、チャプターの設定で直してください。初回の準備で作ったチェックシートの
  名前の期も、同じだけずらします

## 8. メンバー名簿・写真を入れる

1. メニュー `⚙️ 設定` > **`メンバー名簿`** の「一括取り込み」（メンバーブックの HTML・表計算からの貼り付けなど）、
   または `⚙️ 設定` > **`Spreadingから名簿を更新`** で、メンバーを入れます。
   **名簿の並び順が、メンバーブックの掲載順・発表順**になります
2. メニュー `⚙️ 設定` > **`BNI 素材フォルダ`** に、写真・雛形・作ったファイルを置く Google ドライブのフォルダを登録します
3. メニュー `⚙️ 設定` > **`メンバー写真`** で写真を入れます（氏名で自動で照合します）

業種区分（8つ）は Spreading のカテゴリのグループ名に合わせてあります。チャプターで区分が違うときは、
非表示の **「業種区分マスタ」** シート（キー・表示ラベル・色1・色2・ブロック表示名・巡回順）を直します
（メニュー「表示 > 非表示のシート」から表示に戻してから直します）。名簿の「業種区分」と、ここの「キー」を同じ名前にします。

## 9. スライドの雛形を登録する

| 雛形 | 置き場所 | 登録するところ |
|---|---|---|
| ビジター紹介・ゲスト紹介・代理紹介・ビジタープレゼン | `docs/templates/` の見本 | `⚙️ 設定` > `PowerPointテンプレート（ビジター用）` |
| 定例会スライド（前半・後半）・メンバープレゼン | 見本は別にお渡しします（`docs/templates/README.md`） | Drive に置いて `⚙️ 設定` > `大きなスライド` にリンクで登録 |
| 事前MTG（朝イチMTG） | 登録しなくても使えます（同梱の既定のひな形） | デザインを変えたいときだけ `大きなスライド` |

- 見本は、実在の方の氏名・写真を「氏名」「会社名」と灰色の画像に、チャプター名を「〇〇」にしてあります。
  チャプターのデザイン・名前に直してから登録してください。**差し込みに使う図形（文字の枠・写真の枠）は消さないでください**
  （決まりは `docs/templates/README.md`）
- 見本の**音楽・効果音・動画は無音**にしてあります。定例会スライドの画面の「音楽の差し替え」で入れられます
  （図形の名前が、どの音を入れる所かの目安です）
- 前半の雛形には、アンバサダー・ディレクターのページ（「見本　一郎」「見本　花子」）があります。
  リージョンの方のお名前・写真に直してください
- 役員・サポートチームなどのページは、雛形の中の文字と写真をそのまま使います。期が替わったら、PowerPoint で直してください

## 10. 役職・チーム、スピーカーローテーション、トークスクリプト

1. メニュー `📝 役職ごとの入力` > **`入力状況の一覧・事前MTGのパワポ`** の「役職・チーム（半期ごと）」で、
   その期の担当者と委員会・チームを登録します（割り振り表のビジターホストもここから読みます）
2. メニュー `📝 役職ごとの入力` > **`スピーカーローテーション（書記兼会計）`** で、メインプレゼンの順番を決めます。
   最初はメンバー名簿の順です
3. メニュー `📊 スライド・冊子をつくる` > **`トークスクリプト（台本）`** の「ひな形の編集」で、チャプターの台本に直して保存します。
   最初のひな形は `docs/samples/トークスクリプトのひな形.tsv` と同じもので、`{チャプター}` にはチャプター名が入ります

## 11. メール・Gemini API・ウェブアプリ

- **メール**: メニュー `⚙️ 設定` > `メールテンプレート` で、件名・本文・CC・BCC を直します。
  別のアカウントから送る「メール送信用の Web App」を使うときは、**合言葉（トークン）を必ずチャプターで決めたものにしてください**
  （コードに書いてある初期値は、このリポジトリで公開されているためです）
- **Gemini API**: メニュー `⚙️ 設定` > `Gemini API・モデル` に、Google AI Studio の API キーを入れます
  （メンバーリストの読み取り（OCR）と、AI 割り振りで使います）
- **ウェブアプリ**（ダイアログが出ない環境向け・任意）: README.md の「ウェブアプリの更新（URLを変えずに）」の手順でデプロイします

## 12. 準備の状況を確かめる

メニュー `名簿システム` > **`🏠 メニュー画面をひらく`** の右側「準備の状況」が、すべて ✓ になっていれば準備は終わりです。
! の項目は、その横のリンクから設定できます。

---

## 期が替わるとき

- **次の期のルーティンチェックシート**: メニュー `⚙️ 設定` > `足りないシートを作る（ルーティンチェックシートなど）`。
  前の期のシートを写して、開催日の列（1行目の開催日・2行目の回数）だけを新しくします
  （チャプターで足した項目や書式は、そのまま引き継ぎます）
- **役職・チーム**: 10.の画面で、新しい期の担当者を登録します。期が替わると、メンバー名簿の「役職」にも反映します

## 新しい版を入れるとき

```bash
git pull
clasp push
```

ウェブアプリを使っているときは、続けて README.md の「まとめ（毎回この4行）」のとおり `clasp version` と
`clasp deploy -i <デプロイID> -V <番号>` も実行します。

## うまくいかないとき

| 困ったこと | すること |
|---|---|
| メニュー「名簿システム」が出ない | MANUAL.md の「準備：メニューが出ていないところから」 |
| 初回の準備でシートができなかった（何か入ったスプレッドシートで始めた） | `⚙️ 設定` > `足りないシートを作る` |
| チャプターの設定を保存したのに、チェックシートができない | `⚙️ 設定` > `足りないシートを作る`（できない理由が出ます） |
| 画面が「サーバーエラー」になる | 5.の許可がまだです。`🔧 動作確認` > `Googleの権限を確認・許可する` |
| トークスクリプトに「〇〇」が残る | MANUAL.md の「Q: トークスクリプトに『〇〇』が残ります」 |
